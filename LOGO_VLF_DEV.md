## 🎯 Logo VLF dev

### Descripción

El logo de VLF dev es una marca profesional que representa:
- **VLF**: Iniciales del desarrollador
- **</>**: Símbolo de código/programación
- **dev**: Abreviatura de developer (desarrollador)

### Diseño

**Características:**
- ✅ Gradiente de colores (azul → índigo → púrpura)
- ✅ Tipografía moderna y profesional
- ✅ Símbolo de código integrado
- ✅ Línea decorativa inferior
- ✅ Versión con nombre del desarrollador

### Variantes

#### 1. Logo Simple
```
VLF </> dev
```

#### 2. Logo con Nombre
```
VLF </> dev
Pablo Eloy Donnet
Desarrollador
```

### Uso en el Sistema

#### Login (Pantalla de Inicio)
- Logo centrado en la parte inferior
- Nombre del desarrollador visible
- Diseño elegante y profesional

#### Dashboard (Panel Principal)
- Logo en el footer
- Nombre del desarrollador con título "Desarrollador"
- Integrado con el diseño general del sistema

### Archivos Relacionados

- `src/components/LogoVLF.tsx` - Componente React del logo
- `src/components/Login.tsx` - Usa el logo en el footer
- `src/components/Dashboard.tsx` - Usa el logo en el footer

### Colores Corporativos

